User-configurable keybindings via `keymap.toml` in the n00n config dir (next
to `init.lua`). Each entry maps an action to a key or list of keys and
replaces its whole default list; `[]` unbinds it:

```toml
[editing]
newline = ["shift-enter", "ctrl-j"]

[general]
quit = "ctrl-c"
tasks = []            # unbind Ctrl+T
```

Writable contexts: `general`, `editing`, `streaming`, `subagent_chat`,
`history_search` (overlay/picker/modal keys stay component-owned). Keys use
dash notation (`ctrl-x`, `shift-enter`) or vim notation (`<C-x>`). `Ctrl+Z`
stays reserved, Lua `n00n.keymap.set` binds still win, bad entries warn at
startup instead of failing, and `/reload` picks up edits.
