Set the terminal window title to the focused session (OSC 2, restored on exit via the title stack) and emit an attention signal when a turn ends or a prompt needs input. Controlled by `ui.notifications` (`off`/`bell`/`osc9`/`all`, default `"bell"`, overridable with `N00N_NOTIFICATIONS`) and `ui.terminal_title`; the bell is suppressed while the terminal is focused. Plugins can notify explicitly with `n00n.ui.notify(msg)`.
