Overhauled the chat keymap: all bindings now resolve through one context-aware
table that also generates the help modal, so docs can't drift from behavior.
Adopted modern conventions — Ctrl+C clears/cancels, Ctrl+D deletes forward or
exits on a second press, Ctrl+L redraws, Ctrl+G opens the external editor,
Ctrl+O toggles transcript details, Ctrl+T opens tasks, and a single Esc
interrupts a running agent or subagent.

- Composer gained undo/redo (Ctrl+_, Ctrl+Shift+Z), a kill ring
  (Ctrl+U/K/W/Y, Alt+Y yank-pop), draft stash (Ctrl+S), and reverse history
  search (Ctrl+R).
- Multi-line pastes collapse into chips and expand to full content on submit.
- Chat scrolling moved to Alt+U/D/G/Shift+G; Ctrl+T and Ctrl+O follow Claude
  Code / Codex conventions.
- Enabled Kitty keyboard alternate-key reporting, so Shift+Enter and
  shifted chords are distinguished on supporting terminals.
